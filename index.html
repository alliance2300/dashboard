i FSP (First Squad Power) is not a stat the game publishes — even lwservers.com, which coined this estimate, computes it from Hero Power (THP) with a calibrated formula rather than reading it off any player profile. We reuse that same published formula (a quadratic fit through 70 real (THP → FSP) samples, calibrated for the 150M–275M THP range, linear beyond it) applied to each commander's own THP. Our alliance's commanders mostly sit below that calibration range, so treat these numbers as a reasonable estimate, not a precise one.

A struck-through name with a "left YYYY-MM-DD" tag means the source stopped reporting that commander on that date — they're kept listed for 30 days (in case it's a temporary blip) and removed automatically after that if they never reappear. Estimated FSP uses the public THP→FSP formula published by lwservers.com — see the note in the FSP Ranking tab. The colored Tank/Air/Missile badge next to a name shows their strongest hero's squad type (Air beats Tank beats Missile beats Air) — lwservers.com only confirms this for about half the roster, so a name with no badge just means that data point isn't confirmed, not that the commander lacks a squad. A dimmed badge means the strongest hero is Kimberly, the game's default starting hero — still a real Tank, but a weaker signal of intentional squad choice.
